# 文案与命名约定

本项目文档、插件界面文案、测试说明共用同一套表述。改动文档或用户可见文案时，对照本页检查即可；
这些约定靠人工 review 遵守，不设自动检查脚本。

## 1. 服务商名称与场景标签

服务商名称使用官方拼写；需要标注部署位置时，统一写成 **`名称（部署方式）`**，
不使用"本机 Ollama"这类前缀写法。

## 2. 术语表

| 统一用法 | 不要使用 | 说明 |
| --- | --- | --- |
| API Key | 密钥、API 密钥、token | 登录框密码字段里的凭据 |
| 配置串（spec） | 配置行、spec 字符串 | 登录框用户字段里的 `preset:model\|opts` 或 `custom\|...` |
| 预设（preset） | 预置、模板 | 内置的服务商配置项 |
| 请求地址（endpoint） | 接口 URL、endpoint 地址 | `custom` 的完整请求地址 |
| 服务端默认模型 | 服务端默认、默认模型（本地服务） | `lmstudio`/`vllm` 不指定模型时由服务端决定 |
| 用户自填 | 自填、自定义填写 | `custom` 由用户提供地址/模型 |
| 本机 | 本地（指运行在本机的服务时） | "本机服务""Ollama（本机）" |
| 本地 | — | 只用于数据/文件位置，如"保存在本地""本地文件" |
| 翻译引擎 | 翻译器、翻译后端 | 插件在 PotPlayer 里的角色 |
| 实时字幕翻译 | 字幕翻译（菜单路径中） | PotPlayer 的菜单名 |

## 3. 标点与空格

- 中文正文使用全角标点：`，。；：！？（）`；代码、命令、URL、配置串里的括号保持半角。
- 中文与相邻的英文单词、数字之间保留 **一个半角空格**：
  `OpenAI 兼容`、`17 个预设`、`v0.1.0`、`HTTP 401`。
- 破折号、引号：中文正文用 `——`、`“”`；代码与配置串用 ASCII 引号。
- 列表项、表格单元格末尾不加句号；整句说明加句号。
- 表格里的"是否/有无"类取值统一为"是/否"或"无"，不写"没有/支持"混用。

## 4. 版本与数字

- 版本号：`v0.1.0`（文档）、`0.1.0`（`GetVersion()` 返回值）。
- 数量：数字与量词之间加空格，如"17 个预设""82 种语言""236 用例"。
- 时间：`2026-11-07`，不写 `2026/11/07` 或 `11 月 7 日`（正文叙述除外）。

## 5. 表格

- 表头统一为名词短语：`场景 / 用户框 / 密码框`、`preset / 协议 / 默认模型 / 备注`。
- 同一列的取值风格保持一致：模型列为模型名或"服务端默认模型"，不混用"空""自填"。
- 服务商按"本机服务在前、云端服务在后、自定义接口最后"排序。

## 6. 检查方式

本页是人工约定：写文档、改用户可见文案时逐条对照，由 review 把关。
服务商命名、术语、标点与中英空格不设脚本检查，避免用正则误伤正常表述。
